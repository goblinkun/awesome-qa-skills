目标契约：

Judge 按以下顺序选择：

1. `rule_based`：检查状态词、必填字段、版本信息和结构。
2. `script`：核验结构化记录、trace 和工件一致性；作为深证据检查接入既有引擎。
3. `agent_judge`：判断范围理解、失败归因及建议是否受到证据支持。Rubric 为“结论有来源、未知不补造、比较对象正确、建议对应缺口”；经人工标注样本校准后才作为 gate。
